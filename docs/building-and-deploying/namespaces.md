# Namespaces

A namespace is a logical grouping of resources, such as [apps](../resources/apps.mdx), [machines](../resources/machines.mdx), [services](../resources/services.mdx), [volumes](../resources/volumes.mdx) and [certificates](../resources/certificates.mdx).

## Creating Namespaces

They are created automatically when you deploy your first resource with a given namespace name. The default namespace is `default`, so if you don't specify a namespace, your resources will be created in this namespace.
